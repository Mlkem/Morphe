# GPS Emulator standalone patch

`gps-emulator-pro-3.36-v1.0.0-beta.1.mpp` is the exact standalone bundle validated
against the original GPS Emulator 3.36 (336) APKM.

SHA-256: `1969de5e29bb56221dee421d1c1a76f449740f5ae7ac437c26357e50d7c9e109`

It contains patch source, its build script, desktop verifier and verification log.
No original/patched APK or signing key is included. The standalone bundle retains
its MIT declaration; the combined collection uses GPL-3.0.

For automatic source updates, use the existing `Mlkem/Morphe` beta source instead
of importing this standalone bundle. See [setup and validation](../../docs/apps/gps-emulator.md).
